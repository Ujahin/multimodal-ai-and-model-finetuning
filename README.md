# multimodal-ai-and-model-finetuning
People flow detection using object tracking and heatmap visualization

## Project Overview

This project detects and tracks people in a video using a pretrained YOLO model. It counts people moving across two horizontal lines and generates a heatmap to visualize pedestrian movement patterns.

## 1. Detection Method

- **Object Detection:** YOLO11n pretrained model
- **Detection Target:** People only (COCO class ID: 0)
- **Confidence Threshold:** 0.25
- **Object Tracking:** ByteTrack
- **Visualization:** Bounding boxes, tracking IDs, IN/OUT counters, and heatmap

YOLO detects people in each video frame, while ByteTrack assigns tracking IDs to follow detected people across consecutive frames.

## 2. Horizontal Line Coordinates

Two horizontal lines are used to count people crossing the designated areas. The line positions are selected using Roboflow PolygonZone.

- **Upper Line:** `(x1, y1)` to `(x2, y1)`
- **Lower Line:** `(x1, y2)` to `(x2, y2)`

Replace these placeholders with the actual coordinates obtained from Roboflow PolygonZone.

## 3. IN/OUT Counting Logic

The center point of each person's bounding box is calculated in every frame. The previous and current positions are compared to determine whether the person has crossed a counting line.

### IN Count
1. A person's center moves from above the upper line to below it.
2. The system detects the downward crossing.
3. The IN counter increases by one.
4. The tracking ID is stored to prevent the same ID from being counted repeatedly in the IN direction.

### OUT Count
1. A person's center moves from below the lower line to above it.
2. The system detects the upward crossing.
3. The OUT counter increases by one.
4. The tracking ID is stored to prevent the same ID from being counted repeatedly in the OUT direction.

**Counting convention:** IN represents downward crossing of the upper line, while OUT represents upward crossing of the lower line.

## 4. Heatmap Visualization

The heatmap is generated by accumulating the center points of detected people throughout the video. Gaussian blurring is applied to smooth the accumulated points.

Areas with higher intensity represent locations where people were detected more frequently.

## 5. Output Files

- `people_flow_output.mp4` — Annotated video showing bounding boxes, tracking IDs, counting lines, and IN/OUT counters.
- `final_heatmap.png` — Heatmap showing the spatial distribution of detected people.
- `heatmap_overlay.png` — Heatmap overlaid on the original video frame.

## 7. Limitations

- ID changes may affect counting accuracy.
- The heatmap represents accumulated detection locations, not walking speed or direction.
- Counting accuracy depends on line placement, detection quality, and tracking performance.
